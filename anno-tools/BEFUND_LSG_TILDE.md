# LSG1910: eine Tilde am Buchschluss — ein Importartefakt

Gefunden beim Annotieren von **Hosea 14** und **Joel 4**: die
franzoesische Ausgabe endet in beiden Buechern mit einem freistehenden
`~` nach dem Schlusspunkt.

    LSG Hosea 14,9   „Mais les rebelles y tomberont. ~"
    LSG Joel 3,21    „Et L'Éternel résidera dans Sion. ~"

## Der Umfang, gemessen ueber alle 66 Buecher und alle fuenf Ausgaben

| Ausgabe | Verse mit `~` | davon Buchschluss |
|---|---|---|
| WEB (en) | 0 | — |
| RV1909mod (es) | 0 | — |
| RIV1927 (it) | 0 | — |
| l1912mod (de) | 0 | — |
| **LSG1910 (fr)** | **16** | **16 von 16** |

**Jede einzelne Tilde steht im letzten Vers ihres Buches.** Es ist also
kein Textzeichen, sondern eine Buchende-Marke, die beim Import stehen
geblieben ist.

**Zehn der elf noch offenen Buecher stehen darunter** — alle kleinen
Propheten ausser Jona (32). Der Agent des jeweils letzten Kapitels wird
die Tilde sehen; sie gehoert in keine Glosse.

Die fuenf uebrigen Buecher (Psalter, Sprueche, Hohelied, Jesaja,
Klagelieder) sind fertig annotiert. **Gegenprobe ueber alle Glossen des
Bestands: keine einzige enthaelt eine Tilde** — der Schaden ist null,
weil der deutsche Text glossiert wird.

## Ein zweiter Fund im selben Vers

LSG Joel 3,21 schreibt „Et **L'**Éternel" mit Grossbuchstabe im Artikel.
Korpusweit steht `L'Éternel` neben dem regelmaessigen `l'Éternel` —
ebenfalls ein Setzfehler, ebenfalls ohne Folge fuer die Glosse.
